Entry for the make.fun bounty [Funniest Sign on a Haunted Server Room Door](https://make.fun/bounty/u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a).

## What it does

`main.py` writes one funny sign line (100 characters, inside the 120-character
gate) to `/output/entry.txt`:

> WARNING: Haunted server room. The ghost has root and reboots anyone who ignores his tickets at 3 AM.

The output is fixed, so every run is byte-identical.

## Run

```bash
python3 main.py
cat /output/entry.txt
```
